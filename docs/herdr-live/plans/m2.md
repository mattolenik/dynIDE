# M2 Terminal-Client Kernel (Tty and Blit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The `herdr_term` crate takes the host terminal into raw mode, delivers its input bytes, and paints a full screen of packed rows with diff-based ANSI, restoring the terminal on every exit path; a throwaway `live-demo` proves it end to end.

**Architecture:** One Rustler resource per open tty (`TtyResource { inner: Arc<Inner> }`). `Inner` owns the `/dev/tty` fd (opened `O_RDWR | O_NONBLOCK | O_CLOEXEC`, its own open file description), the saved termios, a reader thread (poll + read, sends `{:tty_input, bin}`), and one output thread that owns the `BlitEncoder` and its retained frame and performs every host-tty write. `write/2` and `Blit.frame/3` only enqueue (bounded; frames latest-wins) and return. `Drop` on `TtyResource` restores the terminal and stops the threads.

**Tech Stack:** Rust (toolchain from root `rust-toolchain.toml`), rustler `=0.38.0`, `libc` (already in the crate's lock tree), Elixir 1.20.4 / OTP 29, python3 stdlib `pty` for the pty harness.

**Spec:** `docs/herdr-live/design.md` (NIF interfaces: herdr_term Native.Tty and Native.Blit; Rendering pipeline; Input pipeline) and `docs/herdr-live/milestones.md` M2. Reference to port: `src/protocol/render_ansi.rs` (BlitEncoder), `src/client/terminal_setup.rs` (probe, restore), `src/raw_input.rs` (OS parts only).

## Provisional packed cell format (replaced in Task 6)

Until M1's spec lands, `cell.rs` and the fake row source use this 16-byte little-endian record, one per column:

```
<<codepoint::little-32, fg::little-32, bg::little-32, attrs::little-16, width::8, 0::8>>
```

- `codepoint` 0 means blank (draw a space). `width` 1 or 2; `width` 0 marks the continuation column of a wide cell (not drawn).
- `fg`/`bg`: herdr's packed colour (`val >> 24`: 0 = named, low byte 0 reset, 1..16 the 16 colours in `color_to_sgr_fg` order; 1 = indexed, low byte; 2 = RGB `0x02RRGGBB`).
- `attrs`: herdr's modifier bits (bold 1<<0, dim 1<<1, italic 1<<2, underline 1<<3, slow blink 1<<4, rapid blink 1<<5, reverse 1<<6, hidden 1<<7, crossed 1<<8) plus underline style in bits `UNDERLINE_STYLE_MASK`/`SHIFT` from `src/protocol/wire.rs`.
- Decoded type (stable across the format swap; the rest of the crate uses only this):

```rust
pub struct Cell { pub text: CellText, pub fg: u32, pub bg: u32, pub attrs: u16, pub width: u8, pub link: Option<u32> }
// CellText: inline small UTF-8 buffer (e.g. [u8; 16] + len) or String; Eq + Clone.
pub fn decode_row(bytes: &[u8]) -> Result<Vec<Cell>, CellError>;   // CellError on len % RECORD != 0 or invalid codepoint
pub const RECORD: usize;
```

## Rulings baked into this plan

1. **One output thread per tty does both Blit encoding and all host-tty writes.** So the retained frame always equals what was actually written, and a frame is never half-dropped.
2. **"Behind" = a new frame arrives while the previous frame is still pending (not yet taken by the output thread).** The pending frame is replaced (latest wins, `repaint` OR-ed, dropped count incremented); frames never queue. Raw `write/2` bytes go into a FIFO capped at `WRITE_QUEUE_BYTES = 1 MiB`; a write that would exceed it returns `{:error, :backpressure}` and is not enqueued. Frames are not counted against that cap (at most one is pending).
3. **The output thread never blocks indefinitely**: fd is `O_NONBLOCK`; it writes with `poll(POLLOUT, 100ms)` loops and re-checks the shutdown flag each wake. The reader likewise polls with 100 ms timeout.
4. **Retained frame is per tty resource** (inside the output thread's `BlitEncoder`). After `suspend`/resume and after `restore` it is cleared so the next frame is a full repaint with `ESC[2J`.
5. **open/restore sequences.** `open` saves termios, sets raw (`cfmakeraw`, then `VMIN=1 VTIME=0`), writes `ESC[?1049h ESC[?7l ESC[?25l`, then probes `ESC[?u ESC[c`. `restore` (idempotent, `AtomicBool` claim) writes, best effort with a 100 ms total poll budget: `ESC[<u` only if kitty flags were pushed, then `ESC[?1000l ESC[?1002l ESC[?1003l ESC[?1006l ESC[?1016l ESC[?2004l ESC[?1004l ESC]8;;ESC\ ESC[0m ESC[0 q ESC[?25h ESC[?7h ESC[?1049l`, then `tcsetattr(TCSANOW, saved)`.
6. **Kitty keyboard**: probe result is `flags | nil` (nil when no `CSI ? flags u` reply arrived before DA1 or the 250 ms deadline), exposed via `Tty.kitty_keyboard/1`. `open(%{kitty_flags: n})` pushes `ESC[>{n}u` only when the probe confirmed support; default `0` = push nothing. Non-reply bytes read during the probe are kept and delivered first on `subscribe`.
7. **Suspend** runs synchronously on the calling scheduler: restore, `kill(0, SIGSTOP)` (stops the whole VM; the call returns only after SIGCONT), re-raw + re-enter alt screen, clear retained frame, send `{:tty_resumed}`. Blocking a scheduler is moot while the OS process is stopped.
8. **kill -9 of the VM** cannot run any destructor. The `live/bin/live-demo` wrapper saves `stty -g` before and restores it plus the restore sequence after the VM exits, whatever the exit cause. The destructor itself is proven by killing the owning process with `:kill` (skipping `terminate/2`).
9. **Fake row source** lives at `live/apps/herdr_term/lib/herdr_term/demo/fake_rows.ex` (pure, no processes); the demo is a Mix task `mix herdr_term.demo` in `live/apps/herdr_term/lib/mix/tasks/herdr_term.demo.ex`, never started by a supervisor; real M1 wiring is left to M3/the gate.
10. **Pty testing**: Rust tests use `libc::openpty` and open the slave by path through the same `Inner::open_path`; end-to-end tests use a python3 stdlib `pty` driver (`live/scripts/tty_harness.py`) run by `just live-check`.

## Review Focus

1. Restore on every exit path: `restore/1` twice, destructor after explicit restore, destructor without restore — terminal cooked once, sequence written once (Task 1 tests `restore_is_idempotent`, `drop_restores`).
2. A host tty that stops reading must not block `write/2`, `Blit.frame/3`, or VM shutdown/destructor (Task 2 `blocked_reader_*`, `drop_with_blocked_reader_returns_quickly`).
3. Frame shape changes: resize (different width/height) must full-repaint, never index out of bounds; mismatched row widths or missing rows return `{:error, :bad_frame}` instead of panicking (Task 3 tests).
4. Wide cells: a 2-wide cell replaced by two 1-wide cells (and back) must redraw both columns (port reference `invalidated` logic; Task 3 `wide_cell_change_redraws_neighbour`).
5. Suspend/resume and resize repaint the whole screen; a frame dropped while `repaint: true` must still repaint (Task 2 `superseded_repaint_is_kept`, Task 5 harness).

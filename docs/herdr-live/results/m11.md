### PCRE vetting

`:re` (PCRE2) rejects Rust regex `\uXXXX` and `\u{X}` escapes. Six bundled manifests use them
(cursor, droid, qodercli, hermes, kimi, antigravity). `Manifests.compile_regex` rewrites them
to `\x{..}`; the manifests stay verbatim. Rust `$` means end of text without `(?m)`, so
compile options include `:dollar_endonly`. All 22 bundled manifests compile.

## Rulings (with costs if wrong)

Plan scope decisions:

1. Manifests copied verbatim to `priv/detect/manifests`; overrides at
   `<config dir>/agent-detection/<label>.toml`; herdr's remote manifest download dropped
   (no update channel until M18). Cost if wrong: a later channel plus a cache dir.
2. Precedence: override > bundled; a broken bundled manifest disables only that agent
   (known agent falls to idle); a broken override falls back to bundled with a warning.
   Cost if wrong: a bad edit shows as a warning rather than a hard error.
3. Engine in Elixir on `:re` with match limits; a limit hit counts as no match and is
   reported in explain; no kernel fallback unless p95 > 2 ms. Cost if wrong: kernel regex
   later (not needed, p95 ~1 ms).
4. Detection source is the bottom `rows` of the active screen, OSC evidence from Facts,
   cleared on agent change. Cost if wrong: an identical title from a new agent is ignored
   until it changes.
5. One poller, 300 ms tick, scans only for panes whose activity counter moved or whose
   timer is due, at most 4 per tick, hidden panes polled too. Cost if wrong: scan latency
   with many busy agents (4 per tick round robin).
6. Hook reports served with simplified precedence; herdr's stale-session bookkeeping
   dropped. Cost if wrong: a stale hook state until release or agent exit.
7. `done` = idle and not seen; a tab becoming active turns its `:done` panes `:idle`.
   Cost if wrong: a stale done badge.
8. Integration install/uninstall and the settings integrations section deferred; existing
   herdr installs work through ruling 6. Cost if wrong: users install hooks by hand.
9. Agent resume belongs to M17: M11 only provides the label in `App.Session` pane meta
   `:agent` and the `{:agent, id}` Facts row. Cost if wrong: M17 reads a different source.

Ledger rulings:

10. Task 0 kept `[:not_available]` in agent error lists until Task 8 narrowed them. Cost:
    one extra Spec edit visible to siblings.
11. Error-list narrowing ships with the M11 merge, no separate SPEC_PUBLISHED; coordinator
    told by message. Cost: siblings see narrower lists only at merge.
12. Rust `\uXXXX`/`\u{X}` rewritten to `\x{..}` inside `compile_regex`. Cost: a translation
    bug in one helper.
13. `:dollar_endonly` on every manifest regex. Cost: patterns stricter at a trailing newline.
14. Engine budget met, no kernel regex fallback. Cost: revisit if real-screen polls exceed it.
15. Task 3 minors fixed immediately (argv[0]="" env leak, activity after write, `try_lock`,
    fake merge) because kernel churn later costs a handoff. Cost: one extra round.
16. Tracker emits `{:state, eff}` from any call that changes the effective state, so the
    published state never goes stale when the agent clears. Cost: an extra Store event per
    agent change.
17. A hook-adopted agent (no pid) counts misses only on shell probes. Cost: a stale label
    until the shell returns.
18. Task 6 minors folded into a follow-up round. Cost: one extra round.
19. Plugin context `focused_pane_agent(_status)` come from `App.Session` pane meta (the
    published status incl. done), not raw Facts, keeping `Plugins.Context` pure. Cost: one
    field source swap.
20. `agent.prompt` / `agent.send_keys` error lists mirror the pane verbs they wrap, not the
    plan's `[:not_found]`. Cost: a wider documented list.
21. Screen skip and Facts `skipped` only for herdr full-lifecycle hooks (pi, omp,
    mastracode, opencode, kilo, kimi), as herdr. Cost: explain evaluates screens under
    hooks otherwise.
22. Task 8b: `pane.run` and `agent.prompt` declare `backpressure`/`failed`; an empty
    `pane.run` command now writes only the Enter (no paste), accepted by the coordinator.
    Cost: callers that sent an empty command expecting a paste see no paste.
23. Toast done re-check drops only if the pane is gone, no longer finished (not idle/done)
    or suppressed. The server's `seen` ignores client focus (herdr's does not), so a seen
    idle pane still toasts; suppression still applies when focused. Cost: a toast for an
    agent the user is looking at.
24. Go-to filters bound to Tab-cycle (all, blocked, working, idle, done), not herdr's
    `b/w/i/d`, because M17's Goto sends printable keys to the filter text; typed text is
    kept. Cost: rebind keys.
25. Final review: follow herdr and identify an agent that is the pane's root process (no
    `shell: true -> nil` short-circuit). Cost: identifying the shell on each shell probe.
26. Sort hit clip (final finding #10) skipped as cosmetic. Cost: a clipped click target in
    a narrow sidebar.

Deliberate differences from herdr:

- Screen scans continue under full-lifecycle hooks in the sense that a visible blocker can
  override a non-blocked hook state (final finding #8, recorded, not changed).
- Same-level sort order is stable, not most-recent-first.
- `seen` ignores client focus (ruling 23).
- Remote manifest updates are dropped; `server update-agent-manifests` has no equivalent.
- Integration install and the settings integrations section are deferred.
- Hook stale-session bookkeeping is dropped.
- `release_agent` ignores `seq`; no per-source seq map is kept.

## Known gaps and concerns

- Smoke: codex hooks are untrusted (`~/.codex/hooks.json` installed, codex 0.164 needs
  persisted hook trust), so title rules drive codex; non-default launch flags were needed to
  get approval prompts (claude auto mode, codex reviewer, opencode `--standalone`); one
  unreproduced early codex idle in a development run; two opencode smoke sessions landed in
  the user's opencode history.
- opencode `agent explain` under its hook showed no hook reason: fixed by `bc743fb2`.
- macOS foreground job reads argv with padding `round_up(len(exec_path)+1, 8)`, measured on
  macOS 26 only; a mismatch gives an empty argv (fails safe). macOS picks an arbitrary
  64-process subset, Linux the lowest 64; macOS reads the full procargs (bounded).
- Linux `/proc` scan cost is unmeasured (the Linux kernel code passed cargo tests only).
- After a poller restart the agent label is seeded from Facts and cleared by the miss rule
  on a shell probe, but it stays while a non-agent, non-shell job (vim) runs.
- Deferred minors still open: duplicate manifest ids in `load/2` (guarded by the 22-ids
  test); `lines/1` strips a bare trailing `\r`; repeated line splits per region;
  `Identify.label` reports basenames; package entry names for claude/codex/opencode/gemini
  guessed (miss-only); letta guard partial; in-flight `{:alert_due, a}` timers dropped across
  a reload; reconcile/restore paths skip `agents_seen` (self-heals on the next event);
  `watcher_test` fixed sleep; bundled-dir watch and mkdir fallback untested; orphaned
  `send_err` comment and possibly dead fake hooks in `pane_io`; `Integer.mod(.., 5)` in Goto
  hardcoded.
- Sort hit clip (final finding #10) open.

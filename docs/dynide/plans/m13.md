# M13 chrome and UX parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** herdr's mouse-first chrome (sidebar, tab bar, workspaces, modals, settings, onboarding, keybind editing, toasts, themes) as scene nodes drawn by the terminal client and by a dev-only HTML renderer.

**Architecture:** The server builds a declarative chrome tree (`View` plus `HerdrServer.View.*` builders) from `App.Ui` prefs, `App.Session` and the `App.Focus` modal stack; region nodes carry rects, their children are laid out by each client. The terminal client rasterizes the tree once per scene (`Render.Chrome`) into base and top layers plus a hit list; `Input` hit-tests mouse events against it and sends `{:chrome, path, {kind, %{x, y}}}`; the server resolves chrome actions in `App.Chrome` and modal keys in `App.Modal`, both called from `App.Actions.apply/2`.

**Tech Stack:** Elixir 1.20 / OTP 29 umbrella under `dynide/`; ExUnit; one new hex dependency `toml ~> 0.7` (herdr's config format is TOML; decode only, the writer is ours).

**Spec:** `docs/dynide/milestones.md` "M13", the M13 brief (scope items 1-8 below), `docs/dynide/design.md` "Scene contract", and the reference inventory [m13-herdr-chrome.md](m13-herdr-chrome.md) (labels, sizes and defaults to copy).

- Tiny terminals (20x5, 1x1) with sidebar, tab bar and an open modal: scene validates, compose yields full-width rows, nothing is placed outside the size (Task 2 and Task 7 property-style loops over sizes).

## Contracts used by every task

Region rule: a node with a `rect` is a region; children without rects are laid out by the client inside their nearest region. Paths are lists of node ids from the root's children down (the root id is not part of a path). Chrome actions are `{kind, %{x, y}}` with scene-cell coordinates, `kind in [:click, :double_click, :right_click, :middle_click, :drag, :drop, :scroll_up, :scroll_down]`.

Chrome tree produced by `View.compute/2` (ids are exact):

```
:root (props: %{theme: %{name, auto_switch, light, dark}, indicators: :dots | :symbols, mouse: true})
├── :sidebar  id :sidebar  rect  props %{collapsed: bool}
│   ├── :section id :spaces  text "spaces"
│   │   ├── :list id :list  props %{offset: n}
│   │   │   └── :item id {:workspace, ws_id}  props %{active: bool, index: n}
│   │   │       └── :group id {:line, 0} [ :badge id :state props %{kind: :agent_state, state: s}, :text id :workspace ]
│   │   ├── :button id :new   text "new"   props %{action: :new_workspace}
│   │   └── :button id :menu  text "menu"  props %{action: :global_menu, attention: false}
│   ├── :divider id :split  rect (one row)  props %{direction: :vertical, target: :sidebar_split}   (expanded only)
│   ├── :section id :agents text "agents"
│   │   └── :list id :list
│   │       └── :item id {:pane, pane_id} props %{active: bool}
│   │           ├── :group {:line, 0} [ :badge :state, :text :workspace, :text :tab ]
│   │           └── :group {:line, 1} [ :text :agent ]   (agent name, else pane title, else "terminal")
│   ├── :button id :toggle props %{action: :toggle_sidebar, collapsed: bool}
│   └── :divider id :edge rect (1 col, right edge) props %{direction: :horizontal, target: :sidebar_width}
├── :tabs id :tabs rect (top row of the main area)
│   ├── :tab id {:tab, tab_id} text name props %{index: i, active: bool, zoomed: false}
│   └── :button id :new_tab props %{action: :new_tab}
├── :divider id {:divider, split_path} rect props %{direction, path}    (pane splits, as today)
├── :status id :status rect (bottom row, full width)
│   └── :text :mode (props %{mode}), :keycap/:text hint pairs (prefix/resize modes),
│       runtime :text :reload/:tests/:handoff, :text :notice, :text :title, :text :hint
├── :toast id {:toast, ref} rect props %{level, pane}   (per client; Task 11)
└── :modal id {:modal, depth} rect props %{kind, tone: :default | :danger, dim: bool}   (top of the stack only)
    ├── :text id :title, :text id :subtitle (optional)
    ├── body: :text {:line, n} | :list id :list of :item | :input id :input | :section tabs
    └── :group id :actions [ :button id action_atom text label props %{key: :enter | :escape | "c", mods: [...], primary: bool} ]
    plus :menu (role) instead of :modal for context and global menus: rect at the click, children :item {:entry, atom}
```

Server internal events and effects added: events `{:config_loaded, cfg}`, `{:pane_bell, id}`, `{:agent_state, id, state}`; effects `{:alert, alert}`, `{:config_write, [binary], term}`, `{:reload_config}`.
